🧑‍💻 ZM Agency –  Web Application
This project is a web application developed using HTML, CSS, JavaScript. It simulates the functionality of a digital marketing agency website, featuring multiple pages.​

🚀 Features
Multi-Page Layout: Includes pages like About, Services, Portfolio, Pricing, Careers, Blog, FAQ, Contact, and Sign In.

Backend Integration: Utilizes Node.js with Sequelize ORM for database interaction.

Responsive Design: Ensures compatibility across various devices and screen sizes.

User Authentication: Includes sign-in functionality for user access.​

🛠️ Technologies Used
Frontend: HTML5, CSS3, JavaScript

📦 Installation
To run the project locally:

Clone the repository:
git clone https://github.com/zaynounjamal/zm-agency.git
cd zm-agency
Install dependencies:
npm install
Set up the database:

Configure your database connection in sequelize.js.

Run migrations and seeders to set up the database schema and initial data.​

Start the development server:
npm start
Access the application:

Open your browser and navigate to http://localhost:3000 to view the application.
